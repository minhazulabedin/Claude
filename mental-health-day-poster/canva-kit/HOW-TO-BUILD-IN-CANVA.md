# Building poster 3 in Canva

This kit rebuilds poster 3 ("From Being Heard to Creating Change", the scrapbook version) inside Canva,
so the Canva project is the group's own working file. The graphics are ready-made PNGs; all text is typed
in Canva, so every word stays editable.

There are two ways to do it. Route A takes about 2 minutes; route B takes about 45 minutes and gives a
fully native Canva design.

## Route A: import the PDF

1. Open canva.com, click **Create a design → Import file** (or drag the file onto the Canva home page).
2. Choose `poster3-a2.pdf`.
3. Canva converts it into an editable design: the text becomes text boxes and the drawings become
   graphics. Check the fonts afterwards (see "Fonts" below) and fix any line that moved.

## Route B: rebuild it natively

### 1. Set up the page

- **Create a design → Custom size → 420 × 594 mm** (A2 portrait).
- Upload every file in this folder: **Uploads → Upload files**, select them all.
- Optional but very useful: also upload `poster3-a2-300dpi.png`, drop it on the page, stretch it to fill
  the page, set **Transparency** to 40% and **Lock** it. Use it as a tracing guide, then delete it at
  the end.

### 3. Add the text and shapes

Canva measures text in its own units; the pt sizes below are a starting point. Match them against the
tracing guide. Colours are hex codes: click the colour swatch, then type the code.

**Title**, centred, top at Y 44.5 mm

- Fraunces, Black (heaviest), about 72 pt, line spacing 1.06, colour `#2A241C`

**Theme ribbon**, rectangle 263.4 × 21.7 mm at X 78.3, Y 114.3, corner rounding small, colour `#6B4A32`
- "Lived experiences heard: real voices, real change." (exact wording, keep the colon)
- Fraunces, SemiBold Italic, about 30 pt, colour `#F7EFDE`, centred

**Left note**, rectangle 90 × 28.8 mm at X 33.9, Y 148.2, rotated −4°, fill `#F6EFDD`, border `#CBBD9C`

Card text:

1. **Speak up**: Thoughts kept inside · Fear of being judged · Hard to know where to start.
   **Try this:** Start small with someone you trust: "I've been feeling…"
2. **Listen first**: Quick advice, little listening · Interrupting · Judging too fast.
   **Try this:** Give your full attention and hear people out before you judge.
3. **Act together**: Feeling alone with it · Stigma around asking for help · Not knowing what to do.

4. **Create change**: Less stigma · Better support · A seat at the table.

### 4. Layer order

From the bottom up: background paper, watercolour group, sparkles and butterfly, seal, navy ribbon,
notes, cards, tape strips, slogan, steps strip, ribbon text, and the four hands on top. Use
**Position → Arrange** (Forward / Backward) to fix anything that sits in the wrong layer.

### 5. Export

**Share → Download → PDF Print**, tick **Crop marks and bleed** only if the print shop asks for it.
For WhatsApp, download a PNG.

## Fonts

Search the Canva font list for **Fraunces** and **Work Sans**. If Fraunces doesn't show up, either upload
it (Canva Pro: **Brand → Fonts → Upload**; it's free from Google Fonts) or use **Playfair Display** in
Black / Bold Italic, which looks close. Keep to these two families; the course guideline asks for no more
than two or three fonts.
